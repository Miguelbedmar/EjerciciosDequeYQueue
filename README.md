# EjerciciosDequeYQueue

# 📋DESCRIPCION.
Se desarrollara en java cuatro ejercicios utilizando pilas y colas como estructuras dinámicas contando 
con  cuatro ejercicios para trabajar este tipo de estructuras dinámicas.

# EJERCICIOS.
  -  EJERCICIO1 : 
       -  Se creara una aplicación por consaola que permita invertir el texto ingresado por el ususario  utilizando excluisivamente colas
       -  EL aplicativo debera recibir una línea de texto  y apilar cada caracter y luego desapilarlos sin utilizar metodos de conversión inversa
       -   Se deben emplear los metodos PUSH,POP y ISEMPTY
  - EJERCICIO 2:
      - El programa del segundo ejercicio deberá simular una fila de clientes atendidoo por orden de llegada   para ello lo gestionaremos con COLAS 
      - Se deberá gestionar por medio consola la llegada de clientes , atención , mostrar el contenido y consultar el estado de cola  
      - Para gestionar el programa se deberá enseñar un menu que se repetita hasta que el usuario decida salir.
  - EJERCICIO 3:
      -  EL sistema deberá verificar si una palabra o frase es palíndroma es decir una palabra que se pueda leer exactamente derecha a izquierda o de izquierda a derecha
        por ejemplo ojo , oso etc
      -  Se debe utilizar de manera simultanea pilas para la lectura inversa y colas  para la lectura directa 
      -  Debe  normaliar el texto minúscula y eliminar los espacios con .trim()
      -  Los caracteres deberán insertarse en una pila y una cola y comparar los elementos correspondientes al desapilar y desencolar.

  - EJERCICIO 4:   
      -  El programa deberá convertir un entero decimal positivo a binario mediante una pila.
      -  Se apilan los restos de la división entre dos y al desapilarlo obtenemos el binario.

# 🎯OBJETIVO.
El objetivo de este proyecto es practicar las estructuras dinámicas pilas  y colas divididos en cuatro ejercicios para 
tener un desarrollo práctico más óptimo.
